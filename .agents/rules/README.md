# 📜 .agents/rules/ — Diretório de Regras Operacionais dos Agentes

> Este diretório armazena diretrizes modulares e regras de comportamento para os agentes de IA do LawFirm CRM.

---

## 1. Hierarquia de Regras
1. **`AGENTS.md` (Raiz):** Regras de processo soberanas e invariantes globais do repositório.
2. **`.agents/rules/*`:** Regras especializadas de formatação, linting, segurança e isolamento.
3. **`.agents/skills/*`:** Procedimentos operacionais padronizados (SOPs) executáveis pelos agentes.
